# Site Marker – Privacy Policy

_Last updated: 2026-09-18_

Site Marker is a browser extension that displays a visual badge on websites chosen by the user.

## Data the extension handles

- **Hostnames and labels you type in the options page.** They are stored using Chrome's `chrome.storage.sync` API, which keeps them in your browser profile and, if you are signed in to Chrome with sync enabled, in your Google account so they are available on your other devices. They are never sent to the developer or to any third party.

## Data the extension does not handle

- It does not collect browsing history, page content, form data, credentials, or any personal information.
- It does not make network requests of any kind.
- It does not use analytics, tracking, or advertising services.
- It does not load or execute remote code.

## Permissions

- `storage`: to save your list of markers.
- `scripting`: to run the badge script on the sites you configured.
- Optional host permissions: the extension asks for access to each configured site when you save, and only to those sites. Access to sites you remove is revoked automatically.
